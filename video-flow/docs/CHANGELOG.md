# 0.1.0

Первый проход локального Video Flow по 40 рекомендациям: проекты, SQLite, DOCX, editable storyboard, серверные ключи и адаптеры, безопасные очереди, аудиоприоритеты, локальный Whisper, SRT/VTT, Remotion 30/60 FPS, backup/export/restore, diagnostics и Windows package/update scripts.

Это предварительная версия. Реальные платные интеграции, чистая Windows VM, мгновенная остановка Whisper и оставшиеся пункты [приёмки](ACCEPTANCE.md) не объявляются завершёнными.

## Перед выпуском

- [ ] Native Windows/macOS workflows зелёные для нужного коммита.
- [ ] Video Flow quality/browser/render workflows зелёные.
- [ ] Customer package установлен на чистой Windows x64.
- [ ] Проверен update/rollback на копии data/config.
- [ ] На тестовом аккаунте проверены выбранные модели провайдеров.
- [ ] Проверены реальные voice/image/video цены, отмена и истечение ссылок.
