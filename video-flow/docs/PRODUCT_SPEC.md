# Продукт

Локальный инструмент одного пользователя: сценарий → озвучка → раскадровка → изображения → необязательная анимация → субтитры → MP4. Основной сценарий поставки — Windows 10/11 x64. Исходники можно запускать на Linux/macOS с Node LTS.

Проект содержит стабильные UUID сцен/блоков/кадров, shot ID, ревизию, выбранные модели, состояние артефактов и журнал. Поддерживается до 1000 кадров; обязательная приёмка включает dry-run 202 кадров. Lifecycle active/completed/archived отделён от выбранного этапа. Ready определяется проверенным финальным артефактом.

Данные сохраняются между перезапусками. Один и тот же оплаченный асинхронный запрос возобновляется по внешнему ID; потерянный ответ на создание без ID не повторяется автоматически. Статус uncertain требует явного решения после проверки кабинета. Отмена не обещает возврат средств провайдером.

Продолжительность задаёт декодированное аудио. Приоритет — аудио проекта, аудио сцены, TTS блока. Без голоса задаются секунды на кадр. Веса кадров распределяют целое число frame, не меняя скорость голоса. Cut-монтаж, панорама и zoom для статичных изображений реализованы; автоматические титры, музыкальная драматургия и точная реконструкция исходного монтажа не обещаются.

Прогресс детерминирован; стоимость суммируется только в сообщённых единицах конкретного провайдера. Неизвестная цена остаётся неизвестной. Пользователь подтверждает массовые платные действия, повторные варианты и удаление проекта.
