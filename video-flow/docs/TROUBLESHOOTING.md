# Диагностика и ограничения

- Нет связи с backend: Start/Check Backend, затем logs/stderr.log и /backend-monitor. Порт 8787 может быть занят другой установкой; чужие процессы скрипт не останавливает.
- HTTP 401/403: проверьте правильную карточку провайдера, ключ и разрешения. Прямой ElevenLabs и посредник используют разные ключи.
- Uncertain: ответ на платный POST потерян. Сначала проверьте кабинет. Новый вариант может списать средства повторно; автоматическое создание заблокировано.
- Сохранение 409: изменился проект или закончилась фоновая генерация. Обновите данные и повторите сохранение. Поле оставляет локальную правку; приложение не затирает новую серверную ревизию автоматически.
- Whisper: первая загрузка требует сети; используется CPU. Текущий алгоритм confidence — доля совпавших токенов с монотонным поиском, а не оценка качества модели. При неполном распознавании проверьте границы вручную; низкая confidence даёт приблизительный fallback.
- Недостаточно кадров/медиа: сборка возвращает 409 со списком отсутствующего. До исправления старый корректный MP4 не заменяется.
- Нет файлов после переноса: `npm run integrity` проверяет без ремонта и без создания новой базы. Восстановите data/projects из ZIP/backup. Дневной SQLite backup не содержит медиа; для полного восстановления нужен и каталог projects.

Известные ограничения: перенос проекта из настольного интерфейса в Video Flow пока ручной; монтаж нового модуля — склейки, zoom/pan, без автоматической музыкальной драматургии; стандартный Studio открывает композицию с пустыми defaultProps, а не отдельный редактор выбранного проекта; Whisper inference не прерывается мгновенно; pagination каталогов провайдеров ограничена первой страницей; автоматический баланс/цена доступны только в объёме проверенного DTO. Экспорт ZIP выполняется в памяти; лимит восстановления через API — 50 МБ. Для больших проектов копируйте data после остановки.

SYNTX не публикует найденную нами официальную OpenAPI-схему; адаптер сопоставлен с текущими запросами опубликованного сайта. Изменения провайдера могут потребовать обновления. Mock contract tests не подтверждают доступ вашего тарифа или живую генерацию.
