# Windows 10/11 x64

Распакуйте customer ZIP в обычную папку с правом записи, например `C:\VideoFlow`. Избегайте OneDrive и запуска из ZIP. Выполните `Install Video AI Auto.bat`. В пакете есть проверенный SHA-256 Node 24 LTS; установка загружает npm-зависимости и браузер Remotion, выполняет тесты, lint и build. Нужны сеть и свободное место для npm, Chromium, модели Whisper и медиа. Установка из исходников не создаёт готовый EXE; настольный KadroGen собирается отдельным workflow.

Скрипт использует ExecutionPolicy Bypass только для своего процесса PowerShell; настройки машины и пользователя не меняет. Политика организации может запретить запуск — такой запрет нужно решать с администратором, не изменяя глобальные политики.

`Start.bat` запускает один backend, ждёт health и открывает интерфейс. `Stop.bat` проверяет принадлежность процесса этой установке и отправляет запрос корректного завершения. Если остановка ещё идёт, повторите позже. `Check Backend.bat` и `Backend Monitor.bat` показывают состояние.

Папки `data`, `config`, `logs`, `runtime` лежат рядом с `app`. Ключи — `config/.env.local`; проекты и SQLite — `data`. Не удаляйте эти папки при обновлении. Для переноса на другой компьютер остановите сервер и скопируйте data/config; ключи переносите только на свой компьютер.

`Apply Update.bat` принимает новый customer ZIP: проверка содержимого/хешей → stop → backup data/config → замена app → npm ci/check → start/health. При ошибке возвращается предыдущая app и данные из снимка. Checksum защищает от повреждения, но не заменяет проверку источника архива.

Чистая пользовательская Windows VM и реальная установка под её антивирусом требуют отдельной ручной приёмки. CI проверяет Windows runner; успешный Linux build не является доказательством Windows-установки.
