# Работа с проектом

1. Создайте проект. Введите сценарий с пустыми строками между сценами либо загрузите DOCX: первый столбец `S01.01`, второй — голос, третий — визуал. Второй DOCX промптов сопоставляется по ID. Предупреждения импорта показаны до генерации.
2. В «Подключения и ключи» введите нужные ключи. Ключи не возвращаются в интерфейс после сохранения. Без ключей доступны импорт, редактирование и собственное аудио.
3. В «Озвучке» выберите провайдера, Voice ID/модель либо Template ID Lumean. Готовый блок можно прослушать, заменить своим файлом или создать новый платный вариант. Общее аудио имеет приоритет над аудио сцены и блока.
4. Для загруженного общего/сценового голоса запустите Whisper и проверьте confidence. Без достоверного alignment используется явно приблизительное распределение времени. Первая загрузка модели дольше следующих.
5. В «Раскадровке» отредактируйте промпты, движение, камеру и веса времени. Правки сохраняются с задержкой; ошибка оставляет текст в поле для повторного сохранения. Переход между этапами сначала сохраняет ожидающие правки. Утвердите готовые кадры.
6. Создайте изображения и при необходимости анимацию. Массовый запуск требует подтверждения. Ошибка одного элемента не удаляет соседние. «Продолжить» использует сохранённый внешний ID, а «новый вариант» создаёт платную задачу.
7. Подготовьте SRT/VTT и выберите оформление. В «Сборке» выберите 30/60 FPS и создайте MP4. Рендер появляется только после FFprobe-проверки. Исходный звук сгенерированных видеоклипов выключен.
8. Скачайте MP4 и ZIP проекта. ZIP сохраняет готовые медиа без ключей. Восстановление создаёт отдельный проект; исходный остаётся.

60 FPS делает движение по статичным картинкам плавнее. Видео в 24–30 FPS при приведении к 60 FPS получает повторяющиеся кадры; нейросетевая интерполяция здесь не реализована. 60 FPS увеличивает время локального рендера.
