# Локальная безопасность

Модель угроз: посторонняя веб-страница против localhost, DNS rebinding, path traversal, command injection, SSRF, ZIP bomb, утечка ключа и повторная оплата. Сервер слушает 127.0.0.1, проверяет socket/Host/Origin и токен в изменяющих запросах. Не включайте сетевой доступ через reverse proxy без отдельной аутентификации.

Ключи доступны только backend. Логи содержат request ID, тип операции и нормализованную ошибку, без тела сценария, заголовков Authorization и содержимого внешней ошибки. Raw provider errors не выдаются в UI. JSONL ротируется; клиентские секреты не входят в архивы.

Download разрешает только HTTPS, проверяет DNS/IP каждого redirect, отклоняет private/loopback/link-local и закрепляет проверенный IP в HTTPS-соединении. Заголовки авторизации не передаются на CDN. Ограничены размер, redirects и время. FFmpeg запускается без shell, с массивом аргументов, лимитом вывода и AbortSignal.

DOCX и ZIP имеют ограничения числа файлов и распакованного размера. Только известные относительные артефакты восстанавливаются в projects. Все восстанавливаемые медиа проверяются декодером. SQLite, env и logs не раздаются по /files.

Если ключ утёк, отзовите его в кабинете провайдера и сохраните новый через настройки. Удаление локального файла само по себе не отзывает внешний ключ. Не публикуйте data/config или архивы своих проектов, если в них есть личное содержимое.
