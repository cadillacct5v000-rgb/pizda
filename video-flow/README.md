# Video Flow 0.1.0 — предварительная версия

Дополнительный локальный модуль KadroGen по рекомендациям AI Video Flow. Настольный KadroGen в корне репозитория сохраняет анализ YouTube, рерайт, перенос визуальных ориентиров и предпросмотр. Video Flow открывается в браузере и работает со своими проектами. Автоматического переноса проекта между двумя интерфейсами пока нет.

Реализованы React/TypeScript, локальный Express, SQLite WAL, DOCX по shot ID, редактор с автосохранением, загрузка собственного аудио, очереди голос/изображения/видео, адаптеры ElevenLabs/Lumean/FastGen/SYNTX, Whisper, SRT/VTT и сборка Remotion 1080p в 30/60 FPS. Живые платные API без пользовательских ключей не проверялись. Интеграция SYNTX основана на запросах опубликованного SPA и требует проверки на реальном аккаунте.

## Запуск из исходников

Нужен Node.js >=20.19; рекомендуем встроенную в Windows-пакет ветку 24 LTS. Ничего глобально устанавливать не нужно.

```sh
cd video-flow
npm ci
npm run check
npm start
```

Откройте http://127.0.0.1:8787. Для разработки — `npm run dev`. На компьютере без CUDA можно перед установкой задать `ONNXRUNTIME_NODE_INSTALL_CUDA=skip`; Whisper использует CPU. Первая транскрибация скачивает модель и требует сети.

Ключи вводятся в «Подключения и ключи». Сначала статус «ключ сохранён, не проверен»; «подключено» появляется только после успешной проверки. Для прямого ElevenLabs нужен его ключ; ключ посредника вводится в карточке соответствующего сервиса. Обычный KadroGen также сохраняет отдельные поля прямого ElevenLabs и royaltechno.

## Проверки

```sh
npm run check
npx playwright install chromium
node scripts/check-ui.mjs
node scripts/e2e.mjs
```

Последняя команда собирает настоящее MP4 из трёх сцен в 30 и 60 FPS, проверяет FFprobe, экспорт/восстановление и повторное использование внешних задач после перезапуска. Провайдеры подставлены; списаний нет. Дополнительно рассчитывается таймлайн на 202 кадра. Для уже установленного Chromium: `REMOTION_BROWSER_EXECUTABLE` для Remotion, `PLAYWRIGHT_CHROMIUM_EXECUTABLE` для UI.
