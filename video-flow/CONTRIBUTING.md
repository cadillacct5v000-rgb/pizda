# Разработка

Рабочий цикл: небольшое изменение → проверка влияния на downstream → соответствующий тест → `npm run check` → при изменении UI браузерная проверка → при изменении монтажа реальный `scripts/e2e.mjs` → commit.

Не добавляйте any, @ts-ignore, подавление правил или ложные успешные статусы. Тесты используют временные каталоги и подставленные платные провайдеры. В CI запрещены реальные оплачиваемые генерации. Секреты, базы, медиа и `.env.local` не входят в Git или customer package. Версии пакетов фиксирует lockfile; обновляйте зависимости отдельным проверяемым изменением.
