Download `VideoFlow-0.6.2-Windows-x64.zip` and extract fully. For a new install run `Install Video AI Auto.bat`. To update an existing installation, stop it and use its `Apply Update.bat`, selecting this ZIP. Keep backups of data/config. Do not copy the package over an active installation.

The ZIP contains ready frontend, application source, dependency lock and verified Node archive. No user data, keys, or node_modules are included.
