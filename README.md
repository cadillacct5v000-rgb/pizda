# Video Flow 0.6.5 for Windows

Customer package with ready frontend and verified Node runtime. No keys or user projects included.

Text editing/translation now uses GPT-6 Sol (default), Astra or Luna through fal.ai. Existing Claude selections migrate without changing scripts or media. No paid inference is run by migration or package tests. Image stage distinguishes approved plans from generated images and offers a first-frame button.

Run Apply Update.bat in the existing installation and select this ZIP after current tasks have finished. Existing data/config are retained. Fresh installation: extract ZIP and run Install Video AI Auto.bat.

Validation: unit/integration tests, TypeScript, lint, browser workflow. GitHub Actions verifies native Windows installation, Edge rendering and upgrade from 0.6.4 with rollback. Real paid generation/access and voice quality are not verified by mock tests.
