# Video Flow 0.6.0 — Windows x64 preview

Three reference-based art direction variants, side-by-side image comparison, optional five-second video previews, and explicit selection for subsequent Nano Banana frames. Selected style and media survive restart and project ZIP/restore. Existing frames are preserved.

Extract the ZIP, then run Install Video AI Auto.bat and Start.bat. Existing Video Flow users can use Apply Update.bat with the new package; back up data/config first. This is a separate application package from the legacy KadroGen Python EXE.

Verification: 51 automated tests, lint, TypeScript/Vite build and browser selection/reload. Tests use mock paid APIs and real PNG/MP4 processing. Paid output quality and installation on a clean consumer Windows machine have not been verified.

ZIP includes this package's source, lockfile, launcher scripts and verified Node archive. No user projects, credentials, reports or user media. SHA-256 is supplied alongside the ZIP.
