# Kadro.Gen — исходный код

Версия 1.9.0-dev: общие исправления для Windows и macOS / Apple Silicon (включая M4).
Windows: [WINDOWS.md](WINDOWS.md), Mac: [MACOS.md](MACOS.md). Проверки: [VALIDATION.md](VALIDATION.md).
Новый режим YouTube сохраняет ход полного рассказа и использует анализ выборочных кадров исходного видео для визуального стиля новых сцен.
Исходная информация о Windows ниже сохранена; на Mac используйте инструкции из MACOS.md.

Kadro.Gen — бесплатная программа для Windows: из mp3-озвучки, текста сценария или ссылки на YouTube делает готовое видео 1920×1080
(распознавание речи → сцены → описания кадров → картинки → по желанию оживление → сборка с переходами и субтитрами).
Все нейросети — внешние сервисы, работающие по ключам пользователя. Ключи хранятся только в `config.json` рядом с программой
и никуда, кроме выбранных сервисов, не отправляются.

Версия исходников: 1.7.1. Автор: Гриша Ютубер (https://t.me/Grisha_Youtuber_2003).

## Запуск из исходников

1. Python 3.12 (64-бит) и WebView2 Runtime (в Windows 10/11 обычно уже есть).
2. `pip install -r requirements.txt`
3. Скачать ffmpeg для Windows и положить `ffmpeg.exe` и `ffprobe.exe` в папку `ffmpeg/` (см. файл-подсказку внутри).
4. `python app.py` — откроется окно программы. Ключи вводятся в самой программе на экране «Доступ».

Командный режим без окна: `python app.py --run озвучка.mp3 [--provider fastgen] [--mode images|mixed|video] [--refs] [--subs]`.

## Сборка exe

```
python -m PyInstaller --noconfirm KadroGen.spec
```
Результат в `dist/KadroGen/`. Затем скопировать туда папку `ffmpeg/` и файл `KadroGen.exe.config`.
Номер версии задаётся в `app.py` (`VERSION`) и в `version_info.txt`.

## Из чего состоит

| Файл | Что делает |
|---|---|
| `app.py` | окно (pywebview), API для интерфейса, настройки, проверка ключей, прогноз, отчёт, автообновление с Google Диска |
| `ui.html` | весь интерфейс: стили, разметка, логика, русский и английский тексты |
| `pipeline.py` | конвейер: транскрипция, разбиение на сцены, «библия» стиля и промпты (раскадровка), картинки, оживление, сборка ffmpeg |
| `subtitles.py` | субтитры: разбивка по словам и вшивание в видео |
| `rewrite.py` | рерайт сценария из YouTube-ролика или текста |
| `fastgen_api.py`, `nonstop_api.py`, `yougen_api.py`, `royaltechno_api.py`, `secretslider_api.py`, `google_api.py` | клиенты сервисов картинок и видео |
| `llm_api.py`, `openai_api.py` | языковые модели (Claude, Gemini, OpenAI) и распознавание речи (Whisper, AssemblyAI) |
| `tts_api.py` | озвучка: Edge (без ключа), fast-gen · Gemini, royaltechno · ElevenLabs, VoiceGen, Voicer, Lumean |
| `endpoints.py` | адреса API языковых сервисов, в том числе свои прокси из настроек |
| `netutil.py` | терпеливые сетевые повторы и проверка кнопки «Стоп» |
| `docs/instruction.html` | инструкция для пользователя (встроена в программу) |
| `docs/api/` | описания API сторонних сервисов, по которым написаны клиенты |
| `music/`, `fonts/` | фоновая музыка интерфейса и шрифт субтитров |

`config.example.json` — пример файла настроек; настоящий `config.json` программа создаёт сама и в репозиторий он попадать не должен.

## Куда ходит программа

Только к сервисам, ключи которых ввёл пользователь, плюс:
- `drive.google.com` — проверка и скачивание новой версии;
- `youtube.com` — только если выбран рерайт по ссылке;
- `speech.platform.bing.com` — озвучка Edge (без ключа).

## Изменения 1.8.1-dev

- Собственный API-ключ ElevenLabs: включите озвучку, выберите **«ElevenLabs напрямую»**, вставьте ключ и нажмите «Список», затем выберите голос. Пункт royaltechno требует отдельный ключ RoyalTechno.
- Анализ исходника теперь показывает причину отказа API и позволяет выбрать отдельный Gemini/OpenAI/Claude. Для изображений fast-gen нужен доступ `chat.multimodal`, дополнительно к праву генерации видео.
- Новый режим **«Редизайн видео + ритм склеек (эксперимент)»** анализирует каждый найденный план, делает новые кадры с небольшим редизайном и генерирует видео, сохраняя относительный ритм найденных склеек под новую озвучку. Плавные переходы, музыка, титры и точное движение камеры не переносятся. Длинные планы могут делиться на фрагменты с заметными стыками. Анализ и генерация каждого плана расходуют кредиты.
- Исправлены отмена, передача голоса fast-gen, устаревшая операция видео, повторные запросы после ошибок и кэш разных стилей. Отсутствующие изображения больше не подменяются соседними.
- Сохранены существующие улучшения возобновления/разделения полного рерайта, ресурсы и сборочные скрипты репозитория.

Проверка объединённой версии на Linux: 173 теста и 13 подтестов прошли; 4 проверки Windows PowerShell выполняются только на Windows. Платные внешние API локальными тестами не подтверждены. Подробности: [AUDIT_RU.md](AUDIT_RU.md).

## 1.9.0-dev: редактируемая раскадровка и предпросмотр

После рерайта YouTube в режиме редизайна откройте **«Создать раскадровку»**. Текстовая модель предлагает соответствие каждой фразы исходным планам по их содержанию, а не только позиции во времени. Неуверенные соответствия и отсутствие подходящего референса показаны явно. Это предложение модели, которое нужно просмотреть.

В редакторе можно изменить фразу озвучки, описание нового кадра, исходный референс, движение и длительность. Пустая длительность означает «по речи». Если время задано вручную, темп соответствующей фразы подстраивается через FFmpeg, без изменения высоты голоса; изменение скорости более чем вдвое отклоняется. Изменение текста в карточке меняет сценарий. После изменения общего сценария раскадровку нужно построить заново.

Кнопка **«Новый вариант этого плана»** помечает только выбранный план на повторную генерацию при следующем запуске. Готовые изображения и клипы других планов сохраняются в отдельном кэше. Раскадровку можно открыть после перезапуска кнопкой на экране доступа.

Для проверки выберите начало и 20/30 секунд и нажмите **«Собрать предпросмотр»**. Озвучка и распознавание подготавливаются для всего сценария; новые изображения и видео генерируются только для планов, пересекающих выбранный отрезок. Затем можно вернуться к раскадровке и запустить полную сборку: готовые планы переиспользуются. Предпросмотры сохраняются отдельно в `output/previews/`.

Границы планов привязываются к распознанным словам сценария. При сильном расхождении распознавания и текста программа останавливается с ошибкой, а не подставляет относительные тайминги. Семантический подбор использует описания исходных планов и ограниченные наборы кандидатов; он может ошибаться. Можно выбрать любой исходный план вручную или создать кадр без референса.

Это первый этап улучшения монтажа. Точное распознавание плавных переходов, титры, музыка, звуковые акценты и точное повторение траектории камеры по-прежнему не реализованы. Генерация и анализ используют тарифные лимиты выбранных сервисов.

## Video Flow и частота кадров

В KadroGen 1.9.0-dev добавлены редактируемая раскадровка, 20/30-секундный предпросмотр и выбор 25/30/60 FPS на экране параметров. Смена FPS пересобирает локальные клипы, сохраняя сгенерированные исходные медиа.

Отдельный модуль [Video Flow](video-flow/README.md) следует архитектуре React/Node/SQLite/Remotion из 40 рекомендаций: проекты, DOCX, аудио, раскадровка, очереди и 1080p 30/60 FPS. Windows-пакет публикуется workflow «Video Flow validation and Windows package». Это дополнительный предварительный модуль; [реализация и незакрытая приёмка всех 40 этапов](video-flow/docs/ACCEPTANCE.md) перечислены явно. Настольный интерфейс продолжает работать отдельно.
