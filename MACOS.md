# Kadro.Gen для Mac с Apple Silicon

Это исходный код адаптированной версии. Готовый подписанный `.app` в архив не входит.
Целевая платформа — Mac M4, Python 3.12 arm64. Проверка нативного окна и сборки на macOS ещё нужна.

## Установка и запуск

1. Установите Homebrew по инструкции https://brew.sh, если его ещё нет.
2. Распакуйте проект в постоянную папку, например `~/Projects/KadroGen`.
3. Откройте Terminal в папке проекта и выполните:

```bash
bash scripts/setup_macos.sh
bash scripts/run_macos.sh
```

Установка создаёт `.venv`, устанавливает зависимости Python, FFmpeg и Deno.
Deno и пакет `yt-dlp-ejs` нужны загрузчику для обработки современных страниц YouTube.
На M4 используйте Terminal и Homebrew без Rosetta (`/opt/homebrew`).
Окно использует нативный WebKit через PyObjC. .NET и WebView2 на Mac не требуются.

Настройки, очередь, задания и результаты на Mac находятся в
`~/Library/Application Support/KadroGen/`. Ключи сервисов вводятся на экране «Доступ».
Для переноса Windows-настроек закройте программу и скопируйте свой `config.json`
в эту папку. Старые пути к аудиофайлам и cookies нужно выбрать заново.
Переменная `KADROGEN_DATA_DIR` позволяет явно задать другую папку данных.

## YouTube и ошибка fast-gen

Для ролика `https://www.youtube.com/watch?v=OhnfppMraXY` выберите источник YouTube
и сервис рерайта fast-gen. Программа пробует доступные дорожки субтитров,
затем загрузчик yt-dlp, затем звук с распознаванием речи.
Если субтитры недоступны, распознавание звука требует настроенного STT-сервиса.

Если YouTube просит вход, откройте ролик в своём браузере и войдите в аккаунт.
В строке «Доступ к YouTube» выберите этот браузер или локальный файл cookies.txt
в формате Netscape. По умолчанию браузерные данные не читаются. Выбор выполняется
на вашем Mac; файл cookies не нужно отправлять в чат. macOS может запросить доступ
к связке ключей или данным браузера. Кнопка «Сбросить доступ» отключает использование
браузера/файла. Выбранный файл имеет приоритет и снимает выбор браузера.

Вход не гарантирует доступ при ограничении IP, отсутствии прав на видео или
другой блокировке со стороны YouTube. Ошибка показывает отдельно результат
получения субтитров и скачивания звука.

`ConnectionResetError 10054` означает разрыв соединения с сервисом модели или
сетевым посредником. Временные сбои повторяются с задержкой; постоянные ошибки
доступа (например, 401) возвращаются сразу. Полученный текст ролика сохраняется
в `jobs/youtube_sources/<video_id>.txt` до обращения к модели. Повторный запуск
использует этот текст. Если субтитры ролика изменились, удалите именно этот файл
для повторной загрузки. Исходный текст рерайта также сохраняется в `jobs/source_*.txt`.

## Проверки и сборка

```bash
.venv/bin/python scripts/check_environment.py
.venv/bin/python -m pytest -q
bash scripts/build_macos.sh
```

Результат сборки на Mac: `dist/KadroGen.app`. Приложение использует установленный
FFmpeg и Deno из Homebrew; оно пока не является самостоятельным установщиком.
Сборка `.app` должна выполняться на macOS; Linux не создаёт нативный Mac-бинарник.
Apple Developer ID и notarization не настроены. Старое автоматическое обновление
Windows отключено на Mac, поскольку исходный канал содержит Windows-архивы.

В `.github/workflows/macos.yml` подготовлены тесты и сборка arm64 в GitHub Actions.
Workflow ещё не запускался. Он проверяет зависимости, тесты и сборку; ручная проверка
окна, диалогов macOS, доступа к браузеру и реальных сервисов всё равно нужна.

## Проверка на вашем M4

- Окно открывается, музыка/шрифты/инструкция загружаются, русский текст отображается.
- Выбор аудио, перетаскивание файла, открытие результата в Finder, копирование отчёта.
- Указанный ролик YouTube: загрузка текста без входа, при необходимости с выбранным браузером.
- Рерайт через fast-gen с вашим ключом; повтор после сетевого сбоя использует сохранённый текст.
- Озвучка, режимы «картинки / смешанный / видео», субтитры, переходы, очередь и «Стоп».
- После закрытия и повторного запуска сохраняются настройки и очередь.

Реальные генерации используют лимиты/кредиты выбранного сервиса.
