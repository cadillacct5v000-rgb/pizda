Одна настольная программа: скачайте артефакт **KadroGen-1.9.10-Windows-x64** в GitHub Actions, распакуйте и запустите **KadroGen.exe** в распакованной папке. Отдельный Video Flow и установка Node.js не требуются.

В одном интерфейсе: YouTube/рерайт, анализ визуала и ритма склеек, редактируемая раскадровка, предпросмотр 20/30 секунд, FastGen и SYNTX, прямой ElevenLabs и RoyalTechno, 25/30/60 FPS, SQLite-проекты и импорт DOCX.

Перед упаковкой выполняются Python-тесты, проверка JavaScript-моста и self-test уже собранного EXE: SQLite, DOCX, раскадровка, импорт SYNTX и выбор 60 FPS. Платные API подставлены; доступ живого ключа и качество модели требуют проверки на аккаунте. Полная приёмка всех 40 пунктов PDF и точное воспроизведение каждого элемента монтажа не заявляются.


1.9.10: отдельный Elysium для текстов, рерайта, раскадровки и анализа изображений. Ключ Elysium отправляется в https://elysiumai.garden/v1 по OpenAI-совместимому протоколу. Кнопка «Модели с сервера» получает точные ID через GET; для анализа выберите vision-модель, доступную на вашем тарифе. Кнопка «Проверить» делает небольшой платный запрос. Полные ошибки содержат сервис, сервер и статус, секреты скрыты. Исправлены видимость адреса API при использовании только vision и синхронизация общего ключа. Живой платный запрос Elysium не выполнялся.

1.9.10: JSON-режим для GPT в анализе; устойчивый разбор оформления ответа;
локальное сохранение исходного ответа до разбора и один текстовый запрос для
исправления синтаксиса при необходимости. Неполные ответы не дополняются
вымышленными данными. Успешные части анализа 1.9.5 переиспользуются.

1.9.10: потоковый анализ через Elysium/OpenAI, статус поступления ответа,
получение готового ответа по отметке завершения и понятная диагностика обрывов.
Автоматических повторов неоднозначно оплаченных POST-запросов нет.

1.9.10: ограниченное и видимое ожидание квоты при создании раскадровки,
потоковые запросы её пачек через Elysium/OpenAI, сохранение готовых пачек,
очистка старых ошибок и понятное сообщение при отсутствии сохранённой версии.

разбора, разделение ошибок API и JSON модели, один запрос исправления формата
без исходных описаний кадров, и проверенное повторное использование готовых
пачек при ручной смене текстового сервиса с тем же сценарием/анализом.
