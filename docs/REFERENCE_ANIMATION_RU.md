# Оживление по характеру исходника — 2.0.25

На шаге 7 «Оживление» в списке «Какие сцены оживлять» добавлен вариант «По характеру оживления исходника». Он использует сохранённый профиль движения, а не копирует исходные кадры, точные траектории или склейки.

## Как получить профиль

Для нового исходника выберите этот режим перед подготовкой сценария: вместе с анализом исходника сохраняется отдельное наблюдение за движением. Для готового проекта откройте «Настроить оживление в дизайне канала», вставьте ссылку и нажмите «Изучить только оживление по ссылке · платно». Эта кнопка не переписывает сценарий, не создаёт изображения или видеоклипы и не применяет изменения до сохранения профиля.

При изучении нового дизайна можно оставить галочку «Также изучить характер оживления»: это дополнительный запрос. Если движение уже изучено в текущей раскадровке, кнопка «Взять оживление из текущего анализа» переносит готовые сведения без запроса к модели.

Проверьте режим «Движение» и нажмите «Сохранить и использовать». В следующих роликах выбранный дизайн канала применяет тот же профиль; повторно изучать движение исходника не нужно. Изменение только профиля движения не меняет ключ картинок дизайна канала.

## Что переносится

Из шести коротких отрезков берётся по три последовательных кадра. Модель сравнивает движение внутри каждого отрезка, отличает сдвиги и приближения камеры от движения объектов и от склейки. Это выборочная оценка характера, а не полный анализ каждой секунды.

- Статика, приближение, отдаление и сдвиги камеры выполняются локально над новыми картинками. Для них не нужна видеомодель.
- Примерная доля сцен с движением объектов используется для выбора нейроклипов по новой раскадровке. Выбор учитывает смысловую роль сцены, лимит видеовставок и риск искажений. Схемы и сложные столкновения не отправляются на нейрооживление автоматически.
- При низкой уверенности анализа нейроклипы не выбираются автоматически. Точные эффекты, деформация отдельных деталей, движения персонажей и ритм склеек не воспроизводятся один в один.
- Если в дизайне канала выбрано «без нейрооживления», сохраняется локальная камера без платных видеоклипов. Для движения объектов разрешите генерацию клипов и проверьте короткую пробу.

Выбор пункта меню не вызывает модель. Изучение исходника оплачивается выбранным сервисом анализа; новые нейроклипы — выбранным видеосервисом. Успешный профиль анализа сохраняется по исходному файлу и модели. Повтор использует готовый результат.

Если профиль ещё не изучен, сборка с этим режимом останавливается до запуска производственного задания и предлагает подготовить исходник или профиль канала. Для первого теста можно сначала подготовить сценарий либо изучить движение отдельно, затем сделать предпросмотр готовой раскадровки.

## Claude Opus

В стартовый список Elysium добавлен `anthropic/claude-opus-5.5` — «Claude Opus 5.5 · автоматически». Его можно выбрать в «Анализе исходника»; изменение этой строки не заменяет модель сценариев. Каталог «Модели с сервера» остаётся источником актуальных моделей и доступных вариантов конкретного ключа.
