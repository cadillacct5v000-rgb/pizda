# Проверка 2.0.20

Исправлены ошибки, найденные при проверке сочетаний функций 2.0.19:

- Обычные кадры канала больше не исключаются из автовыбора из-за слова «diagram» в общих инструкциях оформления. Проверяется описание конкретного кадра.
- «Только содержание → дизайн канала» допускается при создании постановки в студии и расчёте стоимости, даже когда у нового исходника нет заимствованных склеек.
- Для режима только из картинок, локального движения и нулевого бюджета вставок не требуется отдельный ключ видеосервиса. Ключи фактически используемых текстовых и графических сервисов по-прежнему нужны.
- При явном выборе видеовставок отсутствие клипа останавливает сборку с сохранением готового. Молчаливой подмены выбранного видео картинкой нет. Режим «по выбранному режиму» сохраняет прежнее поведение.
- В очередь передаются выбранный FPS и снимок настроек; повторная отправка задания также использует сохранённые параметры.
- Галерея учитывает папку выбранной модели Elysium и показывает отметку видео только у выбранных вставок.
- После изменения описания кадра рекомендации обновляются; ошибочный лимит показывается в интерфейсе без необработанного исключения.
- Повреждённые локальные промежуточные клипы пересобираются без новой генерации картинок. Это не означает автоматическую повторную отправку неопределённых платных заданий Elysium.
- Настройки сохраняются атомарно с `config.json.bak`. При повреждении основного файла читается последняя корректная копия. Если повреждены оба, запись пустых настроек блокируется, чтобы не потерять ключи.

Оптимизации: автовыбор на 2000 планах/150 вставках в локальном сравнении 4,36 → 0,09 с при одинаковом результате; хеш видео для слоёв считается потоком без загрузки всего файла в RAM; кэш миниатюр ограничен; временные ролики с наложенными слоями удаляются после успешной сборки. Готовое видео и утверждённые исходные изображения дизайна сохраняются.

Проверки: полный набор автоматических тестов, настоящий FFmpeg/ffprobe для аудио/видеосборки, отмена и повтор, повторное использование медиа, сохранение проектов, браузерный проход через настройки и раскадровку канала, затем нативная Windows-сборка и проверка EXE. Внешние платные запросы заменены проверяемыми ответами сервисов. Доступность моделей, списания и субъективное качество голоса/генерации не подтверждаются офлайн-тестами.
