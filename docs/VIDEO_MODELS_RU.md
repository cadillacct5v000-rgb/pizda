# Видео и единые локации — 2.0.11

## Видеомодели Elysium

«Доступ» → «Оживление картинок» → «Kling / Gemini / Grok · Elysium».
Ключ и адрес Elysium прежние. FastGen рисует, выбранная озвучка (ElevenLabs)
используется в сборке. Hailuo не является основным вариантом; прежняя настройка
видна только если сохранена в старом конфиге. Для перехода явно выберите новую модель.

- Kling 3.0: `kling-3.0/video`, `generate`, `image_urls=[HTTPS]`, duration строка
  от 3 до 15, mode std/pro, sound=false, multi_shots=false, multi_prompt=[].
- Gemini Omni: `google/gemini-omni-flash-1.2`, `generate`, first_frame_url=HTTPS,
  duration целое от 3 до 15, resolution720p/1080p.
- Grok: `x-ai/grok-imagine-video`, `image-to-video`, image_urls=[HTTPS], index=0,
  duration="6", aspect_ratio16:9, mode=normal, resolution480p/720p/1080p.
  Используется стандартная длительность 6с из схемы. По каталогу до скидок:
  480p $0.108, 720p $0.2025, 1080p $0.36 USD за клип. Это не внутренние $API.

Для всех моделей готовые картинки загружаются в Uguu без ключа хранилища, с
публичным доступом по ссылке до 3 часов. Программа скачивает и сверяет SHA-256
до платного видеозадания. Ключ Elysium, имя проекта и текст сценария не уходят
в хранилище. Старый download_url FastGen и data URI не требуются. Сбой хранилища
останавливает работу до POST /videos. Уже сохранённый ID опрашивается без загрузки
исходника. Неопределённые отправки после 502 остаются заблокированными; это обновление
не сбрасывает их и не доказывает отсутствие задания/списания. GET-опрос и скачивание
завершённых заданий сохраняются. Для диагностики неизвестной отправки нужен ответ
Elysium; приложение не угадывает её результат и не делает платный повтор.

Для первой пробы Grok: 480p, «Только картинки» + «Оживить первые: 1», тот же
предпросмотр из сохранённой раскадровки. Новая модель создаёт новые платные клипы.
Формат Grok сверен с живым /v1/media/models. Платные запуски на пользовательском
ключе при разработке не выполнялись; доступ и результат проверяются первым клипом.

## Единые локации

«Доступ» → «Единые локации» → «Общий интерьер для одной комнаты».
Режим включается отдельно, по умолчанию выключен для сохранения старых проектов.

Текстовая модель группирует планы одной физической комнаты, в том числе возвращения
в неё позже. Отдельные квартиры/комнаты и лестничная клетка не должны объединяться
по одному слову «коридор». Непонятные/абстрактные планы получают пустую привязку.
Анализ идёт пачками до 16 планов и сохраняется; это дополнительные текстовые запросы
по тарифу выбранного сервиса. В предпросмотре анализируются только выбранные планы.

Первый план комнаты становится опорным после завершения автоотбора. Отдельная
генерация эталонного изображения не требуется. Следующие планы получают готовый
опорный кадр первым референсом и инструкцию сохранять архитектуру, двери/окна,
материалы, мебель и цвета. Ракурс, персонажи и действие могут меняться. Другие
комнаты создаются параллельно; кадры одной комнаты — последовательно. Если опорный
кадр не получен, зависимые кадры не отправляются вслепую.

С включённым автоотбором модель сравнивает два изображения: слева эталон, справа
новый кадр; проверяется только правый кадр. При отказе используется существующий
цикл до двух перерисовок. Если все варианты с замечаниями, существующий механизм
сохраняет лучший и показывает число проблемных кадров. Режим повышает связность,
но не гарантирует идеальную одинаковость генераций: просмотрите результат перед
оживлением. Исправлена ошибка, когда одобренный новый вариант мог заменяться старым
забракованным вариантом с более высоким баллом.

Включение имеет отдельный визуальный кэш и создаёт новые кадры выбранного отрезка;
старые картинки, озвучка и сборки не удаляются. Изменение опорного плана обновляет
зависимые планы этой комнаты, не других локаций. Перерисовки оплачиваются сервисами.
Для проверки интерьеров сначала используйте 30-секундный предпросмотр, «Только
картинки» и «Оживить первые: нет». После проверки можно включить выбранную видеомодель.


## Восстановление текстов сцен в 2.0.12

«Тексты сцен» — отдельная настройка от модели оживления. Если FastGen исчерпал часовой лимит текстов и в настройках сохранён ключ Elysium, программа использует выбранную текстовую модель Elysium. Эти запросы оплачиваются по тарифу Elysium. Чтобы сразу работать через него, выберите Elysium в строке «Тексты сцен». Не выбирайте видеомодель в качестве текстовой.

Готовые промпты сохраняются после каждой пачки. Неполный ответ больше не удаляет удачные сцены: следующий запуск дописывает недостающие. Ошибки доступа 401/403 останавливают новые запросы текущего этапа; журнал показывает причину и реальное количество готовых промптов. Генерация картинок не запускается по временным заглушкам. Озвучку, транскрипцию, готовые кадры и базу заданий удалять не нужно.
