# Исправления 2.0.4: отказы генерации изображений

- При отказе фильтра отображаются `generation.content_policy`, номер сцены и рекомендация проверить содержание плана вместо «повторите позже».
- Причина сохраняется в images.json и выводится в основном прогрессе.
- Номер сцены в сообщениях провайдеров совпадает с номером в галерее (с единицы).
- Неудачные сцены больше не называются копиями соседних кадров, если их файла вообще нет.
- Автоотбор сохраняет исходную HTTPS-ссылку именно выбранного лучшего кадра, а не последней попытки. Это важно для Elysium Video.
- Генерация видео ожидает завершения автоотбора картинки. Черновой PNG не отправляется на оживление.
- Перерисовка удаляет старый клип Elysium, чтобы он не использовался с новой картинкой.
- Отчёт показывает отдельный видеопровайдер, разрешение и число первых оживляемых сцен.

Обновление не снимает ограничения сервиса и не обходит фильтры. Если сцена отклонена, откройте раскадровку, проверьте её содержание и исправьте описание; остальные готовые материалы сохраняются.
