KadroGen 1.9.10 — одно настольное приложение

1. Распакуйте весь ZIP в новую папку, например C:\KadroGen-1.9.10.
2. Откройте папку KadroGen и запустите KadroGen.exe.
3. Node.js и отдельный Video Flow для этой сборки не нужны.
4. Выберите FastGen, SYNTX или другой сервис изображений. На экране доступа введите его ключ.
5. Для озвучки выберите «ElevenLabs напрямую» с ключом ElevenLabs либо royaltechno с ключом RoyalTechno. Это разные ключи.
6. Для ролика YouTube включите рерайт, вставьте ссылку и включите анализ визуала. После подготовки проверьте сценарий и создайте раскадровку.
7. Раскадровка позволяет менять текст, визуал, движение и исходный кадр. Сначала можно собрать предпросмотр 20/30 секунд; готовые планы используются повторно при полном запуске.
8. Выбор 25/30/60 FPS находится на экране опций. Приведение видео генератора к 60 FPS не добавляет нейросетевую интерполяцию.
9. Кнопка «Проекты» вверху сохраняет и открывает проекты SQLite. Там же импорт DOCX (ID S01.01, голос во втором столбце, визуал в третьем) и отдельного документа промптов.
10. Результаты — в output, готовые промежуточные файлы — в jobs. Для продолжения откройте сохранённый проект и запустите его снова.

Не удаляйте папку _internal: в ней необходимые компоненты. Сохраняйте свою папку старой версии до проверки нового запуска.

Ограничения: перенос визуала даёт ориентиры и ритм склеек; точное восстановление всех переходов, титров, музыки и движения камеры не гарантируется. SYNTX image/video адаптер проверен на тестовых ответах, живая генерация зависит от аккаунта и выбранных моделей (GPT Image 2 / Wan 2.6). Полная приёмка всех 40 рекомендаций PDF не заявляется.

Если сервис анализа вернул HTTP 503, программа делает ограниченные повторы с паузами. Успешные ответы сохраняются по частям; повтор подготовки использует их из jobs. Постоянную недоступность сервиса программа устранить не может. 17 кадров для ролика 458 с — первый обзор: в режиме «Редизайн видео + ритм склеек» затем отдельно анализируются найденные планы (по три кадра на план).

Gemini 429: программа показывает период и величину лимита, если они переданы сервисом. Суточная квота и квота 0 прекращают автоматические повторы. Уже израсходованная квота не восстанавливается обновлением. Анализ до шести планов объединён в один запрос; все три образца каждого плана сохранены. Если текстовый чат FastGen доступен, можно оставить Gemini для анализа кадров, а рерайт и тексты переключить на FastGen вручную.

Elysium (ключ куплен на elysiumai.garden)
В строках «Тексты сцен», «Автоотбор картинок», «Анализ исходника» и рерайта
выберите Elysium. Введите ключ Elysium в поле ключа: он общий для этих строк.
Адрес https://elysiumai.garden/v1 уже задан, его не нужно вставлять вместо ключа.
Нажмите «Модели с сервера», выберите точный ID модели и нажмите «Проверить».
Загрузка списка делает только GET, проверка выполняет небольшой платный запрос.
Для автоотбора и анализа нужна модель с поддержкой изображений на вашем тарифе.
Список моделей сам по себе не гарантирует доступ к изображениям/балансу.
Тексты, рерайт и источник используют отдельные настройки выбора модели;
модель источника не меняется вслед за моделью автоотбора.
Fast-gen можно сохранить для картинок, видео и распознавания речи.

JSON анализа (1.9.10)
Сохраняются успешные ответы прежних версий; папку jobs не удаляйте.
Ответ модели теперь сохраняется до разбора. Если повреждён только формат JSON,
допускается один дополнительный текстовый запрос для его исправления, без кадров.
Такой запрос тарифицируется сервисом. Обрезанные, пустые ответы и отказы модели
не считаются успешным анализом. Уже отброшенный ответ старой версии восстановить
нельзя — только эта незавершённая часть потребует нового запроса.

Ожидание анализа (1.9.10)
Для Elysium и OpenAI анализ принимает ответ частями (SSE), если сервер выдаёт
поток. Статус показывает поступление данных и число символов, без скрытых
рассуждений модели. Известная отметка завершения позволяет принять готовый
ответ, даже если сервер ещё не закрыл соединение. Обрыв без отметки завершения
не считается успехом и не вызывает автоматический повтор платного запроса.
При ошибке видны тип сбоя, сервер, модель и время отдельного запроса.
Не меняйте провайдера/модель и не удаляйте jobs, чтобы сохранить повторное
использование прежних успешных частей. Доступность Elysium не гарантируется.

Раскадровка (1.9.10)
Раскадровка использует сервис из строки «Тексты сцен», отдельно от анализа
исходника. Лимит Fast-gen виден в статусе; после двух минутных пауз программа
останавливается с сообщением и сохраняет готовые пачки. При Elysium/OpenAI
ответ текущей пачки принимается потоком, с видимым ожиданием и без автоматического
повтора после неоднозначного обрыва. Повторите создание с тем же сценарием,
исходным анализом и сервисом/моделью: готовые пачки будут переиспользованы.
Смена сервиса или модели меняет папку черновика и может вызвать новый анализ
привязки фраз. jobs не удаляйте. Сценарий перед закрытием сохраните в проект
или отдельный текстовый файл.
При сетевом обрыве Fast-gen текущая пачка раскадровки автоматически не
отправляется повторно; в ошибке видны тип и время запроса. Часовой лимит сервиса
обновление не отменяет. При повторе с прежними настройками сохранённые пачки
не требуют новых запросов.

Раскадровка и JSON Fast-gen (1.9.10)
Исходный ответ сохраняется до разбора. Программа различает JSON модели и
повреждённый/пустой ответ самого API. Для повреждённого JSON модели возможен
один дополнительный текстовый запрос для исправления формата; он оплачивается
сервисом. HTML, обрезанный ответ и отсутствие ответа не считаются готовой пачкой.
При выборе другого сервиса в «Текстах сцен» теперь можно использовать готовые
пачки прежнего сервиса, если сценарий и исходный анализ полностью совпадают.
Никакого автоматического переключения и отправки запросов другому сервису нет.
Для Elysium выберите Elysium и доступную GPT-5.4; сохранённый ключ общий для
строк этого сервиса. Не удаляйте jobs и не меняйте сценарий при восстановлении.

Режим и стиль исходника (1.9.10)
При сохранённом анализе или раскадровке стиль берётся из исходного ролика.
Описывать «Свой стиль» вручную не требуется. В генерацию передаются стиль и
референсы исходных планов; результат генерации нужно просмотреть.
Режим «Только картинки» теперь сохраняется при запуске и предпросмотре.
Чтобы не заказывать видеоклипы, также поставьте «Оживить первые» в 0/«нет».
Готовый MP4 состоит из картинок с озвучкой и длительностями/склейками по планам;
генерируемого движения персонажей в этом режиме нет. В режимах «Только видео»,
«50 на 50» и при включённом оживлении первых сцен нужен доступ к видео.
Если запрошенные клипы не получены, картинки не подставляются вместо них молча.
Не меняйте сценарий, голос и референсы при повторе, чтобы использовать готовое.
