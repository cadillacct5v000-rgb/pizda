# Продолжение работы после сохранения версии 1.8.0

Работа приостановлена по просьбе пользователя. Общие исправления, Windows-сборка
и новый режим анализа исходного видео опубликованы в main.

## Что уже реализовано

- Исправления YouTube, настройка локального браузера/cookies, обновлённый yt-dlp.
- Полный полученный текст обрабатывается последовательными частями с сохранением
  готовых частей; визуальный профиль по выборочным кадрам используется в новых сценах.
- Подготовлена Windows-сборка с FFmpeg, ffprobe, Deno и EJS; прежний автоапдейтер отключён.
- В Linux прошли 104 теста и 13 подтестов. Два несовместимых с Windows тестовых
  фикстура исправлены отдельно и проверены локально.

## Оставшийся функционал

1. Точный монтаж по исходнику: определить границы кадров и переходы, сохранить
   таймлайн, подогнать новые изображения/видеофрагменты и озвучку под длительности.
2. Музыка: использовать исходный отдельный трек либо добавить разделение смешанной
   дорожки с проверкой качества. Нынешний анализ кадров звук не анализирует.
3. Голос: для нового текста подключить модель нужного голоса/voice_id сервиса TTS.
   Простое извлечение исходной речи не озвучивает переписанный сценарий.
4. Прогнать живой сценарий https://www.youtube.com/watch?v=OhnfppMraXY с fast-gen:
   captions/audio, chat.multimodal для кадров, рерайт, озвучка, новые сцены и финальный монтаж.
   Cloud egress ранее отклонял YouTube и API fast-gen; реальные API-проверки не выполнены.
5. Проверить смысловую полноту рерайта на реальном длинном ролике; тесты подтверждают
   передачу всех фрагментов и порядок, но не гарантируют отсутствие ошибок модели.

Цель пользователя: новый текст и новые кадры при сохранении темы, всего хода
рассказа и похожей визуальной подачи. Точные склейки, музыка и голос — следующий этап.
