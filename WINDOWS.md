# Kadro.Gen 1.8.0 для Windows 10/11 x64

Старый `KadroGen.exe` не обновляется заменой `.py` рядом с ним или установкой Python.
Для исправлений нужен заново собранный EXE либо запуск новых исходников.

## Готовая сборка

Откройте Actions → Windows build в репозитории и выберите последний успешный запуск.
В разделе Artifacts скачайте `KadroGen-Windows-x64` (нужен вход в GitHub).
Распакуйте архив артефакта, затем вложенный `KadroGen-Windows-x64.zip`.
Сохраните папку `KadroGen` целиком в отдельном месте и откройте `KadroGen.exe`.
Папка `_internal` должна оставаться рядом: в ней библиотеки, FFmpeg и Deno.
В Windows также требуется Microsoft Edge WebView2 Runtime.

Если успешной сборки ещё нет, готовый EXE недоступен. ZIP с исходниками из меню
Code → Download ZIP сам по себе не является готовой Windows-программой.

Для переноса ключей закройте обе версии и скопируйте свой `config.json` рядом с новым
EXE. Старую папку и результаты сохраните. Автообновление с прежнего Google Диска
отключено, чтобы чужой релиз не заменил исправленный вариант.

## Запуск исходников

Распакуйте свежий ZIP проекта. Дважды нажмите `SETUP_WINDOWS.cmd`, дождитесь
успешного завершения, затем откройте `START_WINDOWS.cmd`.
Установка использует WinGet: Python 3.12, FFmpeg, Deno, WebView2 и зависимости Python.
WinGet входит в Microsoft App Installer; обновите его через Microsoft Store,
если команда отсутствует. Запускайте от обычного пользователя.

Если PowerShell сообщает, что выполнение скриптов запрещено, разрешите локальные
скрипты для своего пользователя командой `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`.
Для скачанного ZIP Windows может требовать «Свойства → Разблокировать» до распаковки.
Корпоративную политику самостоятельно обходить не следует; в таком случае используйте готовый EXE.

## Ошибка YouTube с cookies

1. Откройте ролик в браузере и проверьте, что видео доступно вашему аккаунту.
2. В обновлённой программе в строке «Доступ к YouTube» выберите браузер с вашим входом.
3. На Windows рекомендуем Firefox: Chrome/Edge могут блокировать чтение или
   расшифровку cookies. При ошибке занятой базы полностью закройте браузер.
4. Альтернатива — выбрать свой локальный `cookies.txt` в формате Netscape.
   Его не нужно отправлять разработчику или в чат.

Программа сначала пробует субтитры и запасной загрузчик, затем звук и распознавание.
Установка JS runtime не заменяет авторизацию и не отменяет ограничения IP/аккаунта.
При блокировке YouTube используйте доступную расшифровку: «Показать текст видео»
на сайте → источник «Мой текст» в программе. Такой обход даёт только текст, без видеостиля.

## Полный сценарий и визуальная подача

В режиме YouTube выберите «Полный сценарий + стиль ролика».
Полный полученный текст передаётся на рерайт последовательными частями; завершённые
части сохраняются при сбое. Короткая сводка не заменяет исходный текст.
Модель всё равно может ошибиться: проверьте результат на экране редактирования.

Видеоряд загружается отдельно в уменьшенном разрешении. Программа анализирует
выборочные кадры по всей длительности (обычно один примерно на 30 секунд, максимум
120 кадров), сохраняет наблюдаемые цвета, композицию и виды кадров. Эти описания
используются в новых сценах. Это не точное копирование монтажа: движения камеры,
точные склейки, музыка и голос по этим кадрам не определяются.

Для fast-gen нужен доступ `chat.multimodal` и модель Gemini с изображениями.
Если доступа нет, программа явно остановит полный режим; текстовый режим остаётся
доступен. Анализ использует лимиты/кредиты выбранного сервиса.

## Самостоятельная сборка и проверки

После установки исходников: `powershell -File scripts/build_windows.ps1`.
Скрипт выполняет тесты, собирает приложение и проверяет комплектные инструменты.
Нативный GUI и живые сервисы дополнительно проверяются на Windows с вашими ключами.
