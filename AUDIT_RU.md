# Разбор и исправления — 9 ноября 2026

Изучены предоставленные Python-модули, связанная логика интерфейса, настройки, сборочные спецификации, документы и журналы. Документы и ответы API использовались как данные проекта. Изменения сделаны в отдельной копии. Исходные вложения сохранены.

## Подтверждённые проблемы и исправления

1. **Свой ключ ElevenLabs некуда вводить.** Прямого клиента не существовало: были только посредники. Добавлены официальный API, отдельный пункт и поле ключа, проверка доступности голосов, список голосов и сохранение/удаление ключа. Модель Multilingual v2. Проверка списка не доказывает наличие прав синтеза и баланса — это явно указано в статусе.
2. **Несовместимые ID голосов между сервисами.** При переключении выбирается сохранённый голос именно нового сервиса или пустое поле. Gemini Algenib не передаётся как новый голос ElevenLabs автоматически. Ключи RoyalTechno и ElevenLabs явно различаются.
3. **Повторные платные TTS-запросы после любой ошибки.** Общий обработчик резал длинный текст даже после отказа авторизации, квоты или сбоя уже созданной задачи. Теперь деление как запасной путь разрешено только при явной ошибке длины. ElevenLabs делится заранее; готовые фрагменты сохраняются при сбое. POST после сетевого обрыва автоматически не повторяется.
4. **Ошибочные файлы принимаются за озвучку.** ElevenLabs проверяет фрагменты FFprobe, а конвейер проверяет итоговую длительность до публикации в кэш.
5. **Голос fast-gen находился не в том поле.** В актуальной GenerationCreateRequest это поле верхнего уровня `voice`, не `options.voice`. Исправлено по публичной OpenAPI-схеме.
6. **Устаревшая операция видео.** `flower_video_from_image` отсутствует в публичном списке возможностей fast-gen. Заменена на `flow_video_lite_from_keyframes` с запасным `flow_video_from_keyframes`; для нового режима подбираются Omni Flash 3–10 s.
7. **Неверный запрос отмены fast-gen.** Заменён DELETE генерации на документированный POST `/api/v6/operations/cancel`. Состояния canceled/cancelled терминальные.
8. **Отмена превращалась в ошибку генерации или успешный QA.** Cancelled теперь проходит через общие обработчики, ожидания повторов прерываются. Флаг сбрасывается при принятии задания интерфейсом, а не после того, как пользователь уже успел нажать «Стоп». Фоновые пулы завершаются до разрешения следующего запуска. Длительный синхронный HTTP-вызов может всё ещё ждать своего таймаута.
9. **Буря запросов при accounts_exhausted.** Недоступная операция исключается на пять минут для общей группы сцен, постоянный отказ ключа отключает его для текущего запуска. Отклонение содержания прекращает перебор моделей для этой сцены.
10. **Копии соседних кадров скрывали провал генерации.** Автоматическая подстановка удалена: работа останавливается с сохранением готового. Новый режим также не подменяет отсутствующие видео статичными картинками.
11. **Кэш игнорировал смену визуальных параметров.** Добавлены отдельные визуальные варианты по стилю, качеству, референсам, HD и профилю исходника. Старые платные материалы не удаляются. Новые варианты могут потребовать генерации заново; прежний плоский кэш автоматически не мигрируется.
12. **Настройки могли перезаписывать друг друга.** Операция изменения настроек из интерфейса сериализована. Удаление TTS-ключа сохраняется и не восстанавливается визуально. Ключ RoyalTechno для озвучки доступен и при невыбранном провайдере его картинок.
13. **HTTP 400 скрывал причину.** Запрос анализа fast-gen использует каноническую модель `google/gemini-auto` и поля публичной ChatCompletionRequest. При отказе выводится код/сообщение сервиса с маскировкой переданного ключа. Добавлен отдельный выбор анализатора Gemini/OpenAI/Claude. Для OpenAI reasoning-моделей исправлены параметры лимита ответа. Точная причина ошибки со скриншота неизвестна: тела ответа и ключа в материалах нет; исчезновение ошибки на аккаунте пользователя не подтверждено.
14. **API-ключ fast-gen мог уходить на внешний URL результата.** Результаты скачиваются отдельным запросом без заголовков авторизации сессии API.
15. **Не хватало файлов для запуска.** Приложенные CMD ссылались на отсутствующие scripts/*.ps1. Добавлены скрипты Windows/macOS и минимальная инструкция, сборочные specs допускают отсутствие необязательных fonts/music.

## Что изменено в работе по исходнику

Ранее: до 120 отдельных кадров, текстовый профиль оформления, сцены по общим правилам 3–7 секунд и фиксированные переходы. Это не было анализом монтажа.

Добавлен отдельный экспериментальный режим. FFmpeg ищет склейки по изменению изображения; модель анализирует три последовательных кадра каждого найденного плана. План получает описание оформления, предполагаемого движения, промпт небольшого редизайна и референс. Сцены строятся по исходной монтажной карте с масштабированием под новую озвучку. Все планы в этом режиме генерируются как видео; случайные переходы отключены, короткий клип подгоняется по скорости вместо длинного замороженного хвоста.

Рерайт полного текста сохраняет факты и порядок событий, допускает улучшение хука, ясности и ритма, убирает повторы и призывы к подписке. Улучшение качества и достоверность моделью автоматически не доказываются: редактор сценария сохранён.

## Что ещё ограничено

- **Полное копирование визуала и монтажа не реализовано.** Нет точного трекинга камеры, выделения всех плавных переходов, анимации типографики, музыки и звуковых акцентов. Детектор может ошибаться. Это показано в интерфейсе, README и инструкции.
- Длинные планы делятся до десяти секунд. Непрерывность движения между генерациями не гарантируется. При изменении темпа/сценария смысловая синхронизация приблизительна: сейчас используется относительное время, а не выравнивание исходного и нового текста по событиям.
- Нужны живые проверки аккаунта: право fast-gen `chat.multimodal` для анализа и `video.generate` для генерации, тарифные ограничения, реальные голоса ElevenLabs и лимиты. Публичные схемы проверены без ключей; платные генерации не выполнялись.
- Изображения/видео других посредников, нативный Windows/macOS GUI и сборки не запускались. Исправление всех возможных ошибок всех внешних сервисов не заявляется.
- Несколько ключей картинок поддерживаются исходным кодом; оживление по-прежнему использует первый ключ каждого видеосервиса. Это отдельный оставшийся дефект распределения нагрузки.
- Общие прогнозы цены/времени приблизительные; прогноз нового режима на экране основан на числе планов, а не гарантированном тарифном расчёте. При многих планах анализ и генерация могут быть дорогими.
- Lumean содержит унаследованную логику повторного заказа после долгого ожидания; в этой версии она отдельно не переработана. До её проверки для собственного ElevenLabs-ключа используйте прямой клиент.
- Старые спецификации и документы ссылались на отсутствующие GitHub Actions, assets и дополнительные скрипты. Такие проверки и готовые сборки нельзя считать выполненными.

## 1.9.0-dev — первый этап управляемого монтажа

Добавлены `storyboard.py` и `storyboard_cache.py`, редактор планов и отдельный предпросмотр. Для сохранённой раскадровки прежняя относительная привязка заменена предложением текстовой модели по содержанию описаний исходных кадров. Границы новых сцен определяются по распознанным словам. Пользователь видит уверенность/причину, может исправить соответствие и задать новый кадр без референса. Кандидаты для модели ограничены соседними исходными планами и лексическими совпадениями; это не гарантия нахождения лучшего кадра и не проверка истинности повествования.

Ручная длительность меняет темп соответствующей фразы с ограничением 0,5–2x; автоматическая длительность следует речи. Предпросмотр генерирует только пересекающиеся планы, корректно обрезает видео/аудио и субтитры и не создаёт копии скорости. Озвучка/STT при этом подготавливаются для полного сценария, что указано в интерфейсе.

Генерации кэшируются отдельно по содержимому плана/референсу/варианту и настройкам. Переход от предпросмотра к полному ролику и запрос нового варианта одного плана проверены сквозным тестом: остальные материалы не генерируются повторно. Повреждённый кэш заменяется исправными результатами. Отсутствующие исходные референсы и изменённый общий сценарий отклоняются до обращения к TTS. В обычном режиме без сохранённой раскадровки прежний конвейер сохраняется.

Подтверждение: 200 тестов и 13 подтестов на Linux; 4 проверки PowerShell предназначены для Windows. Проверка Chromium с настоящим локальным Python API прошла. Полное воспроизведение переходов, звука, титров и точных движений камеры остаётся вне этого этапа.
